The PublicRSS Intelligence & Security Pipeline

1. Ingestion & Sanitization

Fetched with strict 5MB limit, timeouts, and SSRF restrictions. Strips all HTML/script tags and bounds metadata to exact specifications. URLs are strictly excised from AI payloads.

2. Gemma Inference

Exactly 7 sample articles sent inside explicit <UNTRUSTED_FEED_DATA> isolation tags to thwart adversarial prompt injection.

3. Three-Layer Validation

Layer 1: JSON syntax • Layer 2: Pydantic types, enums & forbidden keys • Layer 3: Semantic sanity (no title mirroring, no prompt leaks). Automatically triggers Attempt 2 with corrections if needed.
